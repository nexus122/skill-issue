# Skill Issue

> Stop procrastinating. It's a skill issue.

Extensión de Chrome (Manifest V3) que combina un temporizador Pomodoro con bloqueo de sitios. Cuando arrancás una sesión, los sitios de tu blocklist quedan bloqueados hasta que termine — si entrás igual, te lo hace saber.

## Features

- Temporizador Pomodoro configurable (trabajo/descanso)
- Bloqueo de sitios durante la sesión, con lista de dominios predefinida y personalizable
- Sin pausa — una vez que empezás, la única salida es abandonar (y queda registrado)
- Lista de tareas de la sesión, con posibilidad de arrastrar las incompletas a la siguiente
- Historial de sesiones
- Logros que desbloquean temas visuales (Rojo, Matrix, Vacío, Oro)
- Sonido al terminar sesión/descanso
- Español e inglés

## Instalación (modo desarrollador)

1. `chrome://extensions`
2. Activar "Modo desarrollador"
3. "Cargar descomprimida" → seleccionar esta carpeta

## Stack

Vanilla JS, sin bundler ni dependencias. Manifest V3.
